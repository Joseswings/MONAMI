# Monami 

Aplicación web de monitoreo y coordinación logística. El proyecto comienza
desde cero y no debe reutilizar código ni arquitectura de otros proyectos.

## Stack acordado
- Frontend: React, Vite y TypeScript.
- Backend: FastAPI.
- Refine es opcional y se evaluará después para partes administrativas.

## Alcance funcional
- Roles: cliente, empresa y conductor.
- Flujo de pedidos, asignación a flota propia o paquetería aliada,
  seguimiento, entregas e incidentes de ruta.
- La demo puede simular GPS, incidentes y propuestas de ruta.
  No presentarlos como integraciones reales.

## Forma de trabajo
- Antes de cambios amplios, presenta un plan breve y espera que lo revisemos.
- Implementa una etapa pequeña por tarea.
- No agregues dependencias sin explicar para qué se necesitan.
- Al terminar un cambio, ejecuta y reporta las verificaciones disponibles.
- Distingue decisiones confirmadas de aspectos todavía pendientes.
